# Unified Search

البحث الموحّد يفحص جميع أنواع الأرشيف أو أنواعًا محددة، ويعيد نوع النتيجة ودرجة المطابقة والسجل الكامل. يمكن لواجهة Premiere استخدام `timeSeconds` داخل الاقتباس أو مقطع الترانسكريبت للانتقال إلى موضعه أو إنشاء Marker بعد المعاينة.

أمثلة بحث:
- كل من ذكر بابكو
- معلمو الدراز
- الصور المرتبطة بضيف معين
- اقتباسات عن التعليم
