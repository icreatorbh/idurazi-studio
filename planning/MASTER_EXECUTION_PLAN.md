# Master Execution Plan

**Version:** 3.0  
**Status:** Canonical

## Stage 1 — Editing Intelligence

### 1A Core Platform
Database abstraction, SQLite, migrations, transactions, job queue, backup, recovery, diagnostics.

### 1B Editorial Intelligence
Transcription, diarization, identity resolution, mentions, archive, semantic search, evidence, assets.

### 1C Premiere Intelligence
Timeline inspection, MOGRT, lower thirds, markers, chapters, inserts, B-roll suggestions, multi-camera technical matching.

### 1D Reliability
Undo, recovery, autosave, diagnostics, integration tests, production-readiness gate.

## Stage 2 — Finishing Intelligence
Creative grading, LUTs, skin tones, audio restoration, subtitles, mastering.

## Stage 3 — Publishing Intelligence
Exports, platform derivatives, metadata, thumbnails, scheduling, publishing records.

## Stage 4 — Archive Intelligence
Preservation packages, provenance, knowledge graph, historical timelines, integrity checks.

## Stage 5 — Institution Intelligence
PostgreSQL, multi-user access, permissions, APIs, collaboration, optional Docker and MCP.

## Immediate implementation unit

**Stage 1A: Database Abstraction + SQLite Migration + Job Queue + Recovery**

No Stage 2 implementation may start before the Stage 1 acceptance gate passes.
