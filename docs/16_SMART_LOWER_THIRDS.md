# Smart Lower Thirds

يستخدم Ollama قائمة الأشخاص المحلية والترانسكريبت الموقّت. لا يسمح للنموذج باختراع شخص غير موجود في المستودع.

كل اقتراح يحتوي على الوقت، الشخص، الثقة، القالب، وحقول النص. لا يتم إدراج MOGRT مباشرة؛ يتحول الاقتراح إلى مهمة تتطلب موافقة.

## ملاحظات الدقة
- أضف أسماء بديلة مثل الكنية أو الاسم المختصر.
- استخدم Transcript بتوقيتات.
- راجع الاقتراحات منخفضة الثقة يدويًا.
