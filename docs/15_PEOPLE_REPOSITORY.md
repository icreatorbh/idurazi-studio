# People Repository

يدير الأشخاص الذين يظهرون في برامج iDurazi. البيانات محفوظة محليًا في `database/people.json` في هذا الإصدار لتقليل متطلبات التثبيت. مخطط SQLite الموجود في `database/schema` يبقى هو مسار الترحيل اللاحق.

## الحقول
- الاسم العربي والإنجليزي
- الصفة
- البرنامج
- قالب MOGRT الافتراضي
- أسماء بديلة للمطابقة
- ملاحظات

## الاستخدام
1. شغّل Local Service.
2. افتح تبويب الأشخاص.
3. أضف الضيف واحفظه.
4. نفّذ التفريغ أو الصق Transcript.
5. افتح Smart Lower Thirds واضغط تحليل.
6. راجع الاقتراحات ثم أرسلها إلى المعاينة.
