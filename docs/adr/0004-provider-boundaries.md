# ADR 0004: Provider Boundaries

## القرار
عزل الخدمات الخارجية والمحلية خلف عقود Provider وحقنها عبر ProviderContainer.

## السبب
منع اقتران النواة بمزود واحد، تسهيل الاختبار، ودعم التشغيل المحلي أو البعيد وDocker لاحقًا دون إعادة هيكلة.

## النتيجة
Docker يبقى خيار نشر، وليس شرط تشغيل. تبديل Ollama أو Whisper أو التخزين يتم على مستوى التسجيل فقط.
