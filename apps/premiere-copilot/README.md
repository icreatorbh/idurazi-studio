# iDurazi Premiere Copilot

هذه واجهة Premiere لمنصة iDurazi Studio. لا تشغّل Ollama أو Whisper داخل UXP؛ اتصل بتطبيق `apps/local-service` على المنفذ 37841.

## التحميل
حمّل هذا المجلد داخل UXP Developer Tool. افتح Sequence، ثم اختبر الخدمة من الإعدادات.

## الأمان
Markers وMOGRT والتغييرات المستقبلية تمر عبر Preview. التراجع الحي لبعض العمليات يبقى صالحًا أثناء جلسة الإضافة فقط.
